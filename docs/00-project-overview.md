# 음성 LLM API·YOLO 기반 재난 구조키트 자동 구성 시스템

## 프로젝트 주제

본 프로젝트는 사용자의 음성 명령을 구조화된 작업지시로 변환하고, YOLO 기반 비전 인식과 두산로보틱스 M0609 협동로봇을 연계하여 재난 구조키트를 자동 구성하는 시스템을 구현한다.

사용자가 키트 종류와 물품·수량을 자연어로 요청하면 STT와 LLM이 의도를 분석하고, 검증된 JSON 명령과 키트 레시피를 생성한다. 이후 로봇은 카메라 영상에서 필요한 물품을 인식하고 파지·배치한 뒤 완성된 키트를 다시 검사한다.[[1]](https://app.notion.com/p/LLM-API-YOLO-3cd0f4c1b9cc80cb899fe6c73576acd3?pvs=21)

기존의 고정 좌표·고정 순서 기반 Pick & Place와 달리 다음 요소를 결합한다.

- 자연어 명령에서 키트 종류, 대상 물품, 수량 및 실행 의도를 추출
- LLM 출력을 곧바로 실행하지 않고 명령 검증기와 작업 레시피를 통해 로봇이 수행 가능한 명령으로 제한
- YOLO Segmentation을 이용해 대상 물품과 위치를 인식하고, 인식 결과에 따라 작업 순서를 생성
- 완성 결과를 재촬영하여 작업 실행 여부가 아니라 실제 키트 구성 결과를 기준으로 성공 판정
- 음성 명령, 비전 검출 좌표, 작업 상태 및 결과를 PostgreSQL에 연결하여 추적

## 프로젝트 내용

시스템의 기본 처리 흐름은 다음과 같다.[[2]](https://app.notion.com/p/3ce0f4c1b9cc8097aa3dd9943fe321d6?pvs=21)

1. 마이크로 사용자의 음성 명령 입력
2. 제공된 Baseline 코드 기반 STT로 음성을 텍스트로 변환
3. LLM이 키트 종류, 물품, 수량 및 실행 의도를 분석해 JSON 명령 생성
4. 명령 검증기가 허용된 품목·수량·동작인지 확인하고 작업 레시피 생성
5. M0609이 관찰 위치로 이동해 RGB-D 카메라로 물품 진열 영역 촬영
6. YOLO Segmentation으로 물품의 클래스와 영역을 인식
7. 초기 구현에서는 검출 영역의 2D 중심과 체커보드 기반 좌표 변환을 이용해 파지 좌표 계산
8. ROS2와 DART를 통해 M0609 및 그리퍼의 Pick & Place 실행
9. 작업 완료 후 키트를 재촬영하고 레시피와 실제 구성 결과 비교
10. 결과와 오류를 저장하며, 확장 구현 시 누락 물품 추가 또는 오투입 물품 방출 수행

주요 모듈별 역할은 다음과 같다.

| 모듈 | 주요 역할 |
| --- | --- |
| 음성·LLM | STT, 사용자 의도 분석, 구조화된 JSON 명령 생성 |
| 명령 검증·레시피 | 지원 품목·수량·명령 검증 및 실행 작업 목록 생성 |
| Vision AI | YOLO Segmentation 학습·추론, 물품 인식 및 최종 키트 검사 |
| 좌표 변환 | 카메라 검출 좌표를 로봇 작업 좌표로 변환 |
| ROS2·Robot | 작업 순서 관리, M0609 이동, 그리퍼 파지·배치 및 상태 전달 |
| DB·결과 관리 | 구조화 명령, 검출 좌표, 작업 상태·결과 및 오류 저장, 객체 식별 좌표값, 로봇팔 움직임 좌표값 등 기록 |

학습 및 평가에는 `로봇행동 데이터_소형 객체 파지`를 활용한다. 후보 품목은 컵라면, 햄, 수세미, 마스크, 일회용 숟가락, 여행용 티슈, 양갱, 샴푸, 분유의 9종이며, 데이터 수량·클래스 분포와 실제 구매·파지 가능성을 확인한 뒤 최종 키트 구성품을 확정하였다. 실제 환경 평가는 클래스별 약 20~30장의 별도 이미지를 수집해 수행한다.

훈련과정에서 학습한 RGB-D 카메라 보정, 객체 인식 모델 학습·추론, ROS2 인터페이스, M0609 및 그리퍼 제어, 음성 명령 처리, Docker 기반 실행환경 구성 기술을 하나의 Vision–Language–Action 연계 파이프라인으로 통합한다.

## 프로젝트 구조

### 프로젝트 목적

- 음성·언어 AI, Vision AI 및 협동로봇을 결합한 VLA 자동 키팅 공정 구현
- 자연어 명령을 검증 가능한 구조화 명령으로 변환하여 로봇 작업의 예측 가능성 확보
- 비전 기반 물품 인식과 작업 후 재검사를 통해 누락·수량 오류·오투입 여부 판정
- 반복 시험을 통해 각 모듈과 전체 공정의 성능을 정량적으로 평가

### 추진 구조

| 단계 | 주요 실행 내역 | 주요 산출물 |
| --- | --- | --- |
| 1. 기획·설계 | 요구사항, 대상 품목, JSON 스키마, 시스템 인터페이스 및 평가 기준 정의 | 요구서, 시스템 구성도, 데이터 흐름 |
| 2. 데이터·모듈 개발 | 데이터 분포 확인, 전처리·학습, STT·LLM 명령 변환, DB 및 ROS2 기본 기능 구현 | 학습 데이터, 모델, 모듈별 테스트 결과 |
| 3. 로봇 통합 | 체커보드 좌표 변환, 파지점·그리퍼 폭 설정, Pick & Place와 최종 검사 연동 | 통합 실행 파이프라인, 키팅 데모 |
| 4. 검증·개선 | 품목별 반복 파지, 전체 공정 20회 시험, 실패 원인 분석 및 제한된 재시도 구현 | 평가 결과표, 오류 기록, 개선 내역 |
| 5. 문서화·발표 | 수행 경과, 기술 선정 근거, 문제 해결 과정 및 최종 결과 정리 | 최종 보고서, 발표자료, 시연 영상 |

### 정량 평가 계획

- 음성: 사전 정의 명령에 대한 STT 문장 또는 키워드 인식률
- 명령 변환: 필수 필드와 형식을 충족한 JSON 유효 응답률
- 비전: 클래스별 Precision, Recall, mAP50
- 파지: 클래스별 파지 성공률
- 시스템: 전체 공정 20회 기준 End-to-End 성공률
- 안정성: 중단 없이 연속으로 성공한 작업 횟수

### 구현 범위

1차 목표는 음성 명령 입력부터 물품 인식, 순차 파지·배치, 완성 키트 검사 및 결과 저장까지의 최소 수직 흐름을 완성하는 것이다. 검사 결과에 따른 자동 재시도·오류 물품 제거, 3차원 형상 기반 파지점 계산 및 DB 세부 관리 범위는 기본 기능의 안정성을 확인한 뒤 적용하는 확장 기능으로 관리한다.

## 활용방안 및 기대 효과

- **소량 다품종 키팅 자동화:** 자연어로 키트 종류와 수량을 변경할 수 있어 고정 레시피만 수행하는 자동화보다 품목 변경에 유연하게 대응할 수 있다.
- **작업 오류 감소:** 작업 후 비전 검사를 통해 물품 누락, 수량 불일치 및 오투입을 확인하고 결과를 기록할 수 있다.
- **작업 편의성 향상:** 장갑 착용 또는 양손 사용이 어려운 환경에서 음성 기반 비접촉 작업지시 인터페이스로 활용할 수 있다.
- **추적성과 품질 관리:** 명령, 검출 좌표, 실행 상태, 검사 결과를 동일 작업 흐름으로 저장하여 오류 원인 분석과 반복 공정 개선의 근거로 활용할 수 있다.
- **물류·제조 현장 확장:** 재난 구조키트뿐 아니라 부품 키팅, 주문별 포장, 생활용품 세트 구성 등 유사한 Pick & Place 공정으로 확장할 수 있다.
- **교육·연구 활용:** STT–LLM–Vision–ROS2–Robot–DB를 연결하는 모듈형 구조를 통해 AI와 협동로봇 통합 자동화의 설계·검증 사례로 활용할 수 있다.

기대 효과는 단순 시연 성공 여부가 아니라 음성 인식, 명령 변환, 비전 인식, 파지 및 전체 공정의 정량 평가 결과와 실패·개선 기록을 근거로 검증한다.
